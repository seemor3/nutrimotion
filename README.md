# NutriMotion
 
An Android application built as a university group project, designed to help users track workout activity and plan exercise routes.
 
## Features
 
- Log and track workout activity
- Plan exercise routes using the Google Maps API
- Clean, user-focused interface for reviewing activity over time
## Tech Stack
 
- **Language:** Java
- **Platform:** Android
- **APIs:** Google Maps API (route planning)
## My Contribution
 
This was a group project completed as part of my Computer Science degree at Newcastle University. My main focus was **front-end and UI design** — building the interface for tracking workouts and reviewing activity, with an emphasis on usability and a clean, intuitive layout.
 
## Status
 
This project was developed for academic purposes and reflects the codebase at the time of submission. It is preserved here as a portfolio piece rather than actively maintained.
